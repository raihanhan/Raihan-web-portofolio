Website portofolio pribadi ini dibangun untuk menampilkan profil, rekam jejak akademik, pengalaman, serta proyek-proyek yang pernah saya lakukan. 

---

## Tentang Proyek Ini
Website ini dirancang sebagai resume interaktif untuk recruiter dalam menilai kemampuan saya. Saat ini, saya berfokus untuk mengejar karier antara sebagai **Data Analyst** atau **IT Support**.

---

## Fitur dan Halaman
Portofolio ini memiliki beberapa bagian utama (Single Page Application):
* **Hero Section**: Perkenalan singkat tentang saya sebagai *Fresh Graduate Master of Information Technology* lengkap dengan tautan untuk mengunduh CV.
* **Summary & Skills**: Menampilkan ringkasan profesional, *hard skills* dan *soft skills*.
* **Education**: Riwayat pendidikan .
* **Experience**: Pengalaman kerja.
* **Projects**: Menampilkan studi kasus data interaktif.
* **Publications**: Menampilkan publikasi jurnal paper.
* **Certificates**: Kredensial profesional.
* **Contact**: Formulir kontak interaktif.

---

## Tech Stack
Berdasarkan struktur kode, proyek ini menggunakan teknologi berikut:
* **Framework**: [Next.js](https://nextjs.org/) / React
* **Styling**: Tailwind CSS (Utility classes)
* **Icons**: `react-icons`
* **Form Handling**: Formspree API
